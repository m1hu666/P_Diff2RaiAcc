# Failure-analysis source location

The final, editable failure-analysis sources have moved to the repository-level
[FINAL-CODEBOOK](../../FINAL-CODEBOOK/README.md) directory. That directory is
the single authoritative location for:

- trial-level category assignments and diagnoses;
- task-level case notes;
- human-readable category definitions and boundary rules; and
- the machine-readable taxonomy.

This pointer is retained so older links to `docs/failure_analysis/` explain the
move. Do not restore or maintain duplicate copies here. Generated catalogues,
statistics, and the full report remain under `result/`.
